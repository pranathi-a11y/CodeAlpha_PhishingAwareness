# PhishGuard — Phishing Awareness Training

PhishGuard is a responsive, offline-friendly educational website that helps people recognise phishing attempts and respond safely. Built for the CodeAlpha cybersecurity task.

## Features

- Clear lessons on phishing messages, fake websites, suspicious links, attachments, urgency, and social engineering
- Three fictional phishing scenarios with explanations
- Two real-world case studies with primary-source links
- Practical prevention checklist
- Five-question quiz with feedback, score, and restart
- Responsive layout; no accounts, credentials, analytics, or backend

## Run it

Download or clone this repository and open `index.html` in a modern browser. No installation or build step is required.
